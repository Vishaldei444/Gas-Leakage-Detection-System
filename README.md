# 🚨 Arduino Gas Leakage Detection System

## 📖 Description

The Arduino Gas Leakage Detection System is a simple safety project that detects the presence of harmful gases using an MQ-2 Gas Sensor. When the gas concentration exceeds a predefined threshold value, an LED turns ON and a buzzer sounds an alarm to alert users about a possible gas leak.
This project demonstrates the use of sensors, actuators, and Arduino programming for real-time environmental monitoring and safety applications.

## 🎯 Objectives
- Detect gas leakage using the MQ-2 gas sensor.
- Alert users through LED indication and buzzer alarm.
- Monitor gas levels through the Serial Monitor.
- Provide a low-cost and easy-to-build safety solution.
